# Easement web (`apps/web`)

Next.js App Router UI for the marketplace and business dashboard.

## Scripts

```bash
npm run dev     # development (slower; not a prod benchmark)
npm run build   # production build
npm run start   # serve production build locally
npm run lint
```

For performance notes, production checks, and what was optimized, see [docs/PERFORMANCE.md](../../docs/PERFORMANCE.md).
